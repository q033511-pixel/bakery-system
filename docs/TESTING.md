### 2. اختبارات SQL — `supabase/tests/ledger_tests.sql`

نفس سيناريوهات المواصفة **ضد قاعدة حقيقية** + إضافات:
- منع البيع من مخزون غير متوفر (بند 17/127) برسالة عربية صحيحة
- Idempotency على مستوى PostgreSQL: نفس operation_id مرة واحدة فقط (بند 39/82)
- لا فاتورة بدون أصناف (سلامة المعاملات — بند 82)

تشغيلها (بجلسة مالك النظام بعد bootstrap):
```sql
select run_bakery_ledger_tests();
-- النتيجة: ✅ ALL DATABASE LEDGER TESTS PASSED
```

### 3. اختبارات RLS (بند 74)

سياسات RLS مطبقة على 42 جدولاً. للتحقق اليدوي بسرعة:
```sql
-- كمستخدم PENDING (تسجيل جديد):
select * from sales;            -- يجب: 0 صفوف
select * from profiles;         -- يجب: صفك فقط
-- بعد تفعيلك كموزع:
insert into sales (...) ;       -- يجب: RLS rejection (لا سياسة INSERT)
select create_sale(...);        -- يعمل فقط إن كانت صلاحيتك sales.manage
```
